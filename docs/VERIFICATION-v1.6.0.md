## 信号経路

```text
コンテナ／デコーダー → Media3のPCM 16 bit経路 → Aurio AudioProcessor
  Direct  → PCMバッファのコピー
  Enhance → カット／シェルフ／10バンドEQ → ゲインとステレオ幅 → サンプルピーク制御
       → Media3 AudioSink → Android AudioTrack → OSミキサー／接続機器
```

旧版もMedia3のPCM経路に独自EQを1回挿入していました。Aurio内にAndroidの `AudioEffect` を重ねる処理はありません。端末固有の音響効果はOS側で処理されます。Media3のoffloadとfloat出力を無効にして、DirectとEnhanceを同じプレーヤーで切り替えます。24 bitのWAVなどはMedia3が16 bitに変換し、Directは変換後のPCMをAurio内でさらに加工せずに渡します。 [Media3 AudioProcessor](https://developer.android.com/reference/androidx/media3/common/audio/AudioProcessor) · [Media3 AudioSink](https://developer.android.com/reference/androidx/media3/exoplayer/audio/AudioSink)

USBは従来どおり、Androidが報告した形式から互換性のあるミキサー設定を選びます。EQや音量処理を使う間はビットパーフェクトの要件を満たさない扱いにします。API上の対応形式・設定結果と実際の出力は個別に扱います。 [音声出力の実装記録](audio-dsp-v020.md)

## DSPと設定画面

- 10バンドEQは既存の中心周波数と±12 dBの調整を引き継ぎます。低域・高域のカットは2次Butterworth、低音の量は120 Hz、高音の量は6 kHzを境目にしたシェルフです。カットの初期状態はオフで、シェルフの初期値は0 dBです。PCMのサンプルレートに応じて周波数を制限します。 [Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)
- 旧版は各バンドのブースト量を足し合わせて入力を減衰させていたため、複数バンドを持ち上げると出力が大きく下がりました。新しい処理では合成フィルターの最大ゲインを推定します。両端と各バンドの中心を含め、1オクターブを32分割して評価し、1 dBの余裕を加えます。
- 設定の切り替えは20 msでクロスフェードします。フィルターを通した後も内部の演算には倍精度を使います。ゲインと幅はフィルターの状態を保ちながら切り替え、ピークでは全チャンネルに同じ減衰をかけます。減衰からの復帰時定数は80 msです。計測対象はサンプルピークです。
- 正規化は内部解析またはR128／ReplayGainタグを使います。内部解析は400 msのゲートとK重み付けを使ったモノラル・ステレオの推定値です。未解析でタグのない曲は正規化を保留します。解析済みの無音と400 ms未満の曲には正の正規化ゲインをかけません。解析は明示操作で始まり、端末内にキャッシュします。 [ITU-R BS.1770](https://www.itu.int/rec/R-REC-BS.1770) · [OpusのR128コメント](https://www.rfc-editor.org/rfc/rfc7845#section-5.2)
- グラフは実際のフィルター係数から求めます。プリアンプ、聴き比べ用のレベル、正規化やピーク制御は周波数特性のグラフから外れます。サンプルレートが未確認の間は48 kHzを基準として表示します。
- 既存のRoomプリセットに先頭10値のEQとプリアンプを残し、フィルター4値を任意で追加しました。旧形式のフィルターは初期値で復元します。A/B用のレベル調整はEnhance全体の設定です。Roomスキーマと永続URI権限の扱いは従来どおりです。

## PCMの振幅と処理時間

Media3のAudioSink内でAurioの処理直後のPCMを取得しました。24 bitステレオWAVの6 kHz信号を3 kHzローパスに通したところ、44.1 kHz入力では左−13.0973 dB／右−13.0979 dB、48 kHz入力では左右とも−12.9663 dBでした。いずれも係数から計算した値の±0.15 dB以内です。

48 kHzモノラルの1 kHz・振幅0.1のサイン波を10バンドすべて+12 dBで比較しました。実測のRMSは旧回路が入力比−100.91 dB、新回路が−1.09 dBでした。新回路の1 kHzでの合成フィルター特性は+20.09 dB、ヘッドルームに基づく入力ゲインは−21.17 dBでした。

48 kHzステレオの8,640万フレームをWindows上のJVMで連続処理しました。10バンドを+12 dBに設定し、両シェルフを+9 dB、プリアンプを+6 dB、ステレオ幅を120%に設定しました。ハイパス20 Hzとローパス20 kHzを有効にし、2つのトーンにインパルスを加えています。処理時間は67.304秒、最大サンプルピークは1.0、非有限値とフルスケール超過は0件でした。

同じJVMで10秒の48 kHzステレオPCMを処理し、2回のウォームアップ後に5回計測しました。音声1秒あたりの中央値は旧回路の10バンドEQが17.04 ms、新回路の10バンドが19.31 ms、新回路で4フィルターを追加した場合は20.22 msでした。10バンドEQは測定ごとのばらつきが重なるため短時間の参考値です。
