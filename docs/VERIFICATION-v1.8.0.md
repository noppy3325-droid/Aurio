# Aurio v1.8.0 Vinyl Experienceの検証

| 項目 | 内容 |

| 検証端末 | Androidエミュレーター API 37、x86_64、540 × 1200、密度214 dpi |

## 実装

- v1.7.0の途中変更をローカルGitに退避し、公開済みのv1.6.0から作業しました。横置きスタンバイの左に盤と針を表示し、右に再生画面と共通の操作を置きます。狭い横画面では操作側の幅を優先します。
- 盤とジャケットは再生中に1.8秒で1回転します。一時停止中の角度を保持し、針は盤外へ戻ります。盤は短いタップで再生・一時停止を切り替えます。再生位置の操作は共通のシークバーで行います。
- 盤の交換は525 msです。旧盤を左へ送り、新しい盤を右から入れます。再生中はその後125 msで針が戻ります。曲送りが続いた場合は最新の盤を使います。動きを軽減する設定では盤を即時に切り替えます。
- 初期状態では端末の明るさに従い、自動減光はオフです。旧版で保存した明るさ・自動減光を読み込み、前面から離れるか画面を閉じた時点でウィンドウの明るさと点灯フラグを復元します。 [WindowManager.LayoutParams](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#screenBrightness) · [LifecycleEventObserver](https://developer.android.com/reference/androidx/lifecycle/LifecycleEventObserver)

## 再現方法

`VinylMotionTest` はフレーム時間から求める角度と盤交換の状態を確認します。`UiSmokeTest#vinylStandbyUsesSharedSeekAndRestoresPortrait` はMediaSessionに合成音源を入れ、再生中の横置き、針と盤のドラッグ、シーク、曲送り、縦画面への復帰を操作します。`StandbySettingsDeviceTest` は初期値と保存済み設定に加えて、画面がバックグラウンドに入るときの明るさと画面点灯の復元を確認します。

## 共通QA

- 最終APKと計装テストAPKをビルドしました。JVM単体テスト104件が合格し、lintはエラー0件、警告42件でした。
- エミュレーターでversionCode 36のローカル試験版から37に上書きし、ライブラリ、プレイリスト、お気に入り、歌詞、再生履歴、設定、永続URI権限1件を保持しました。その後、同じversionCode 37の最終APKを上書きしました。公開版v1.6.0からの直接の上書き試験は未実施です。
- 最終APKでDirect／Enhanceの切り替えと設定の復元を確認しました。更新確認では公開版v1.6.0を取得し、現在の版より古いと判定しました。
- 30分の横置き連続試験、端末での発熱、実機のUSB-C・Bluetooth・ロック画面の確認は未実施です。
