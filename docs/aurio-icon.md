# Aurio icon

The Aurio icon pairs coral record grooves with a cream stylus on a deep slate gradient. The Android launcher applies its own mask to the adaptive icon. Themed icons use a single-color version of the same mark. The 24 dp notification icon uses the outer groove and stylus to keep the shape clear in the status bar.

The [vector master](design/aurio-icon.svg) shows the 72 dp visible area of the 108 dp Android artwork. Keep the SVG and the Android drawables in `app/src/main/res/drawable` in sync when changing the mark.
