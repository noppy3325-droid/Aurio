# Aurio v5.3 Rev.2 Implementation Plan

**Goal** — Preserve the installed library and playback experience while updating Now Playing, the home feed, and the glass navigation.

**Architecture** — Keep Compose, Media3, and Room. Let the pager own the selected tab. Let the lens follow the pointer in physical coordinates during a direct drag, then hand off to the pager after release. Draw glass from recorded content underneath the controls.

**Spec** — Part A of `LUMA_Music_v5_3_Rev2_Integrated_Revision.md` governs new behavior. Part B supplies regression coverage.

- [x] **Now Playing.** Extract edge and dominant colors from a sampled artwork bitmap off the UI thread. Deliver the artwork and its colors together. Test legibility with bright, dark, and missing artwork.
- [x] **Tabs and glass.** Reuse Backdrop 2.0.1 and the existing quality levels. Measure tab bounds and keep selection semantics tied to the settled page. Test drag direction, cancellation, tab limits, and body swipes. Add a debug comparison with the same production components.
- [x] **Listening and home.** Record qualified listening in the service, add a Room migration, and assemble ranked shelves off the UI thread. Exercise repeated tracks, seeking, old history, missing files, and a new library.
- [x] **Integration.** Build test and release APKs, run unit and device tests, inspect smoke screenshots and performance captures, and sign the release APK with the existing distribution key. Record physical-device checks separately.

See the [verification record](../../VERIFICATION-v0.24.md) for results and limits.
